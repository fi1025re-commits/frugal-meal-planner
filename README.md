# 🍳 5人家族向け 食費節約献立＆買い物リスト作成ツール

**「毎日の献立を考えるのが大変…」「物価高で食費がかさむ…」「子供の好き嫌いが多くて困る…」**  
そんな子育て世帯・5人家族のお悩みを一瞬で解決する、**完全無料・インストール不要・登録不要**のWebアプリケーションです。

---

## ✨ 主な機能と特徴

1. **🎯 1週間の目標予算設定＆追従最適化**
   - 「¥6,500」「¥7,500」「¥8,500」などのプリセットや自由入力で目標予算を設定。
   - 1円単位で差額を計算し、予算内に収まるバランスの良い献立を自動構築します。

2. **👶 お子様ごとの好み・苦手食材個別設定（かぼちゃ・ピーマン等）**
   - 兄弟姉妹それぞれの嫌いな食材（ピーマン、なす、きのこ、かぼちゃ等）や味付けを個別に除外。
   - 同じ材料で作れる「別メニュー提案」も搭載！

3. **🍳 充実の全250品レシピデータベース**
   - 主菜106品・副菜80品・汁物64品の計250品を収録。
   - 鶏むね肉、豚こま、合挽き肉、魚、豆腐、厚揚げ、もやし等をフル活用し、お肉や和洋中の偏りを自動防止。

4. **🛒 スーパーの売り場順 買い物リスト＆LINE送信**
   - 1週間分の食材を「野菜」「肉・魚」「大豆・乳・加工品」「調味料」に通路順で自動合算。
   - 買ったものを消せるチェックボックス＆パートナーへ一発で送れる「LINEで送る」機能付き。

5. **📱 スマホ完全対応＆安心のローカル保存**
   - 面倒な会員登録や個人情報の送信は一切不要。データはお使いのスマホ・PC内に安全に自動保存されます。

---

## 🚀 使い方
ブラウザで開くだけで即座にご利用いただけます。
- 目標予算と家族人数を設定
- 「好み設定」でお子様の苦手な食材を選択
- 「献立生成」を押すだけで1週間分の献立と買い物リストが完成！
